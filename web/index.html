Unlock editing

Reading the board needs nothing. Adding, pausing, re-scheduling or removing a keyword writes to the database, and this page is public — so those calls need your write token, or anyone who found the link could empty your queue.

Where do I find it?

It is the SUPABASE_WRITE_TOKEN line in the .env on the machine that runs the crawler:

sed -n 's/^SUPABASE_WRITE_TOKEN=//p' ~/etsy-scraper/.env

Once it is in, Copy unlock link gives you a URL that unlocks any browser in one click — bookmark it on your laptop, send it to your phone. The token rides in the # fragment, so it is never sent to the server and is stripped from the address bar the moment the page loads.

The database stores only a SHA-256 hash of it, so the plaintext lives nowhere but that file. Your browser keeps it in localStorage and sends it only to your own database, which answers yes or no.
